GroupDocs.Markdown allows you to customize how documents are loaded before conversion. Use [LoadOptions](https://reference.groupdocs.com/markdown/java/com.groupdocs.markdown/loadoptions/) to set a password for protected documents with `setPassword`, or explicitly specify the file format with the `FileFormat` enum (e.g., `FileFormat.XLSX`, `FileFormat.PDF`) to skip automatic format detection.
