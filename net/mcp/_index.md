Everything needed to **install and run** the GroupDocs.Markdown MCP server on the .NET platform. What the server *does* — its tools, use cases, and licensing model — is platform-independent and lives in the [MCP server section]({{< ref "markdown/mcp/_index.md" >}}).

| The .NET build at a glance | |
|---|---|
| Package | [`GroupDocs.Markdown.Mcp`](https://www.nuget.org/packages/GroupDocs.Markdown.Mcp) (current **26.9.0**) |
| One-command run | `dnx GroupDocs.Markdown.Mcp --yes` |
| Container images | `ghcr.io/groupdocs-markdown/markdown-net-mcp` · `groupdocs/markdown-net-mcp` |
| Prerequisites | [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) for the NuGet channel, or Docker |
| Source | [GroupDocs.Markdown.Mcp on GitHub](https://github.com/groupdocs-markdown/GroupDocs.Markdown.Mcp) |
| Release notes | [changelog](https://github.com/groupdocs-markdown/GroupDocs.Markdown.Mcp/tree/main/changelog) · [GitHub releases](https://github.com/groupdocs-markdown/GroupDocs.Markdown.Mcp/releases) |
